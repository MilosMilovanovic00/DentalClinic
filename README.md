# 🦷 DentalClinic

A full-stack web application for managing dental clinic appointments. Built as part of an internship interview process.

> 💼 **Internship Project** — developed as a technical assignment for an internship interview.

---

## 🛠️ Technologies

| Technology | Purpose |
|---|---|
| **Java / Spring Boot** | Backend REST API |
| **Spring Security + JWT** | Authentication & authorization |
| **React** | Frontend |
| **SCSS** | Styling |
| **Maven** | Build tool |

---

## ✨ Features

- 📅 **Appointment scheduling** — Patients can book dental appointments
- 🔐 **Authentication** — Secure login and registration with JWT tokens

---

## 🚀 Running the Project

### Prerequisites

- **Java JDK** >= 8
- **Node.js** & **npm**
- **Maven**

### Setup

1. **Clone the repository**
```bash
   git clone https://github.com/MilosMilovanovic00/DentalClinic.git
   cd DentalClinic/project
```

2. **Run the backend**
```bash
   ./mvnw spring-boot:run
```

3. **Run the frontend**
```bash
   cd frontend
   npm install
   npm start
```

4. **Open the app**

   Navigate to `http://localhost:3000` in your browser.
